# IKRAM Haute Joaillerie & Beauty

Ultra-luxury bilingual (EN / AR) jewelry & beauty boutique built with Next.js, Tailwind CSS, Framer Motion, and Zustand.

## Run locally

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Pages

- `/` — Editorial landing hero & brand story
- `/collections` — Category grid + material/style filters
- `/shop` — Product gallery with quick-view detail drawer
- `/cart` — Concierge bag + WhatsApp order placement

## Configure WhatsApp

Update `WHATSAPP_NUMBER` in `src/lib/products.ts` with Ikram’s business line (country code, no `+`).
